Meta FDE Assessment Playbook

What you're walking into

Your 90 minutes

The loop for every level

At the start, read the problem intro: it summarizes all four levels in one line each. Those lines tell you where your design will need to stretch, so let them shape your Level 1 data model. Then run this loop once per level:

  1. Read the level text twice. Mark each return type and every "returns None / False if…" clause.
  2. Open the level's test file. The first test is usually the example table; the rest are edge cases the text only implies. When the text and a test disagree, the test wins.
  3. Decide what new state the level needs and which one helper will own it (_process, _add, _alive, _log).
  4. Write the happy path, then each failure branch. Validate before you mutate.
  5. Run the tests. Fix the first failure only, then run again. The message tells you the call and the expected value.
  6. When the level is green, read the next level and get going. Don't polish finished code.

Stuck on one test

Give it ten minutes, then move to another failing test in the same level. Credit is per test, so a 7/9 level still scores.

Tempted to rewrite

After minute 45, don't. Extract one helper or add one field instead. A working solution with a clumsy spot beats a half-finished clean one.

Last five minutes

Run every test, delete debug prints, make sure the file imports cleanly, and submit.

Entity classes and one registry

Use when Every level of every problem. Start this way at Level 1, even when a dict of ints would do.

Level 3 and 4 add fields (owner, history, pending events). A small class absorbs them; a dict of ints forces a rewrite.

class Account:
    def __init__(self, account_id: str):
        self.id = account_id
        self.balance = 0
        self.outgoing = 0          # later levels add fields here, not new dicts


class BankingSystemImpl(BankingSystem):
    def __init__(self):
        self.accounts: dict[str, Account] = {}

    def transfer(self, timestamp, source_id, target_id, amount):
        src = self.accounts.get(source_id)
        dst = self.accounts.get(target_id)
        if src is None or dst is None or src is dst or src.balance < amount:
            return None                      # validate everything first...
        src.balance -= amount                # ...then mutate: failures change nothing
        src.outgoing += amount
        dst.balance += amount
        return src.balance

Refactor without breaking Level 1

Use when Level 3 adds timestamped versions of old methods (set_at, get_at, file_upload_at ...).

Old tests re-run. Route old and new methods through one private helper; the old one passes a neutral value.

def _get(self, key, field, timestamp):          # the only real implementation
    entry = self.data.get(key, {}).get(field)
    if entry is None or not self._alive(entry, timestamp):
        return None
    return entry[0]

def get(self, key, field):                       # Level 1 signature unchanged
    return self._get(key, field, None)           # None = "ignore expiry"

def get_at(self, key, field, timestamp):         # Level 3
    return self._get(key, field, timestamp)

Time hook and event heap

Use when Anything that happens later: cashback, scheduled payments, retries, expirations that must fire.

Nothing calls you at the due time. Every public method first applies everything due at or before its timestamp.

import heapq

def _process(self, now):
    while self.queue and self.queue[0][0] <= now:
        due, seq, event_id = heapq.heappop(self.queue)
        event = self.events[event_id]
        if event.canceled:                     # lazy deletion: check state on pop
            continue
        event.apply(self)                      # e.g. refund cashback to event.owner
        self._log(event.owner, due, self.accounts[event.owner].balance)  # history at DUE time

def schedule(self, timestamp, delay, event):
    self.seq += 1                              # tie-breaker: creation order
    heapq.heappush(self.queue, (timestamp + delay, self.seq, event.id))

# first line of EVERY public method, queries included:
#     self._process(timestamp)

TTL entries

Use when Values that expire: fields with ttl, files with ttl, sessions, locks.

Store the absolute expiry once; answer "alive at t?" in one place. Windows are half-open: [t, t + ttl).

def _set(self, key, field, value, timestamp, ttl=None):
    expires = None if ttl is None else timestamp + ttl
    self.data.setdefault(key, {})[field] = (value, expires)

@staticmethod
def _alive(entry, now):
    expires = entry[1]
    return now is None or expires is None or now < expires   # gone AT timestamp + ttl

Value at a past time

Use when get_balance(time_at), "state at T", "who owned X at time T".

Append (time, value) after every change, then binary-search. A None value marks "did not exist".

import bisect

class History:
    def __init__(self):
        self.times, self.values = [], []

    def record(self, t, value):                 # after EVERY change; value None = gone
        self.times.append(t)
        self.values.append(value)

    def at(self, t):
        i = bisect.bisect_right(self.times, t)  # last entry with time <= t
        return self.values[i - 1] if i else None

Backup, restore, rollback

Use when Level 4 of the database, storage and hosting problems.

Snapshots must be copies. Store remaining TTL and re-anchor it to the restore time.

import bisect

def backup(self, now):
    snap = {}
    for key, rec in self.data.items():
        live = {f: (v, None if exp is None else exp - now)     # REMAINING ttl
                for f, (v, exp) in rec.items() if exp is None or now < exp}
        if live:                                               # skip empty records
            snap[key] = live
    self.backup_times.append(now)
    self.backups.append(snap)
    return len(snap)

def restore(self, now, target):
    i = bisect.bisect_right(self.backup_times, target) - 1     # latest backup <= target
    self.data = {key: {f: (v, None if rem is None else now + rem)
                       for f, (v, rem) in rec.items()}          # brand-new dicts
                 for key, rec in self.backups[i].items()}

Ownership, capacity, merge

Use when Users with quotas, files with owners, merging accounts or users.

One add/remove pair owns every size change, so capacity can't drift. A merge re-points everything, then deletes the id.

def _add(self, owner_id, name, size):
    user = self.users.get(owner_id)
    if user is None or name in self.files:
        return False
    if user.capacity is not None and user.used + size > user.capacity:
        return False
    self.files[name] = File(name, size, owner_id)
    user.used += size
    return True

def merge_user(self, id1, id2):
    if id1 == id2 or id1 not in self.users or id2 not in self.users:
        return None
    u1, u2 = self.users[id1], self.users.pop(id2)   # u2's backup leaves with it
    for f in self.files.values():
        if f.owner == id2:
            f.owner = id1
    u1.used += u2.used
    u1.capacity += u2.capacity
    return u1.capacity - u1.used

Intervals: overlap and merge

Use when Salary for a window, double-pay periods, assignments active during [start, finish).

Two lines cover almost every interval question. Merge overlapping periods so they never count twice.

def overlap(a_start, a_end, b_start, b_end):
    return max(0, min(a_end, b_end) - max(a_start, b_start))

def merge(intervals):
    out = []
    for s, e in sorted(intervals):
        if out and s <= out[-1][1]:
            out[-1][1] = max(out[-1][1], e)
        else:
            out.append([s, e])
    return out

Undo and redo

Use when Editors, containers, anything with "revert the last change".

Snapshots (the memento pattern) are simpler than writing an inverse for every operation, and harder to get wrong.

def _change(self, new_text, new_cursor):
    if new_text != self.text:                        # only real changes are undoable
        self.undo_stack.append((self.text, self.cursor))
        self.redo_stack.clear()                      # a new change kills redo
        self.text, self.cursor = new_text, new_cursor

def undo(self):
    if self.undo_stack:
        self.redo_stack.append((self.text, self.cursor))
        self.text, self.cursor = self.undo_stack.pop()
    return self.text

Dependency graph

Use when Jobs or tasks that wait for others, cascading cancels, "reject if it creates a cycle".

Store both edge directions. Adding "A waits for B" makes a cycle exactly when B already waits for A.

def _depends_on(self, start, target):          # does `start` (transitively) wait for `target`?
    stack, seen = [start], set()
    while stack:
        cur = stack.pop()
        if cur == target:
            return True
        if cur not in seen:
            seen.add(cur)
            stack.extend(self.jobs[cur].prereqs)
    return False

Format variants you might meet

Query-array format

Older ICA questions give a list of string commands and expect a list of strings back. Keep the class; add a thin adapter.

def solution(queries):
    store = CloudStorage()
    out = []
    for op, *args in queries:
        if op == "ADD_FILE":
            result = store.add_file(args[0], int(args[1]))
        elif op == "GET_FILE_SIZE":
            result = store.get_file_size(args[0])
        else:
            raise ValueError(op)
        out.append(to_str(result))
    return out

def to_str(value):
    if value is None:
        return ""
    if isinstance(value, bool):        # check bool BEFORE int: True is an int
        return "true" if value else "false"
    if isinstance(value, list):
        return ", ".join(value)
    return str(value)

Raise instead of return

Some specs say an operation "throws". Tests then use assertRaises, so return values don't matter there.

def file_upload(self, name, size):
    if name in self.files:
        raise RuntimeError(f"file {name} already exists")
    self.files[name] = (size, None)

Mistakes that fail tests

Check these before every Run

These are the slips that most often turn a test red. The kit's tests include cases for most of them.

  • Tie-breaks in the wrong directionSort with one tuple key such as (-count, name), and check it on equal counts.
  • Numbers sorted as strings"acc10" < "acc2" and "task_id_10" < "task_id_2". Keep the integer and sort by it.
  • Output format off by one character"name(size)" has no spaces, and a joined list uses ", ". Copy the format from the test, not from memory.
  • None vs "" vs False vs []Return exactly what the spec names for each failure case. Tests compare values exactly.
  • A failed operation changed stateValidate every condition first and mutate last. A rejected transfer touches neither balance.
  • Counter advanced on failureIds like payment3 or task_id_7 count successful creations only, unless the spec says otherwise.
  • Due events applied too lateApply everything due at or before the timestamp before running the operation. Do it in every method, queries included.
  • TTL boundaryAlive means now < t + ttl. At exactly t + ttl the value is gone.
  • Float money2% rounded down is amount * 2 // 100. Floats and round() break on .5 cases.
  • History logged at the wrong timeLazily applied events go into history at their due time. "At time T" means after all operations at T.
  • Snapshot shares objects with live stateCopy on backup and again on restore. Tuples inside dicts are safe; nested dicts and lists are not.
  • Merge forgets somethingMove balance, totals, pending events, ownership and capacity, then delete the old id. A re-created id starts empty.
  • Edge sizesn = 0, n larger than the count, empty storage, unknown ids. Each one has a defined answer.
  • Deleting while iteratingLoop over list(d), or collect the keys first.
  • Changed a signatureKeep every method name, parameter order and default. Some Level 3s put timestamp last.
  • Earlier levels regressedLevel 1 and 2 tests keep running. Re-run everything after each refactor.
  • Empty containers left behindWhen the last field of a record goes, drop the record. Counts of "non-empty records" depend on it.
  • Prefix, substring, suffixstartswith, in and endswith answer different questions, and all of them are case-sensitive.

Integer Container warm-up

Meta's practice test

The practice question in Meta's invite (CodeSignal 'Progressive Filesystem' practice): add / delete, then get_median.

  1. L1add(value) returns the new size; delete(value) removes one occurrence and returns a bool
  2. L2get_median(): leftmost middle of the sorted values; None when empty
  3. L3count_in_range(low, high) and get_kth_smallest(k) (kit extension)
  4. L4undo() / redo() over successful changes (kit extension)
Watch for
  • Median index is (n - 1) // 2 for both odd and even n.
  • Failed deletes are not changes; any new change clears redo.
Reference solution (integer_container_impl.py, passes every kit test) 
from __future__ import annotations

import bisect

from integer_container import IntegerContainer


class IntegerContainerImpl(IntegerContainer):
    """Sorted list + bisect. Every change goes through _insert/_remove so undo/redo reuse them."""

    def __init__(self):
        self._values: list[int] = []          # always kept sorted
        self._undo: list[tuple[str, int]] = []  # ("add" | "delete", value)
        self._redo: list[tuple[str, int]] = []

    # ---- primitives (no history bookkeeping) ------------------------------
    def _insert(self, value: int) -> None:
        bisect.insort(self._values, value)

    def _remove(self, value: int) -> bool:
        i = bisect.bisect_left(self._values, value)
        if i < len(self._values) and self._values[i] == value:
            self._values.pop(i)
            return True
        return False

    def _record(self, op: str, value: int) -> None:
        self._undo.append((op, value))
        self._redo.clear()                    # a new change invalidates redo

    # ---- Level 1 ------------------------------------------------------------
    def add(self, value: int) -> int:
        self._insert(value)
        self._record("add", value)
        return len(self._values)

    def delete(self, value: int) -> bool:
        if not self._remove(value):
            return False                      # failed ops are not recorded
        self._record("delete", value)
        return True

    # ---- Level 2 ------------------------------------------------------------
    def get_median(self) -> int | None:
        if not self._values:
            return None
        return self._values[(len(self._values) - 1) // 2]   # leftmost middle

    # ---- Level 3 ------------------------------------------------------------
    def count_in_range(self, low: int, high: int) -> int:
        if low > high:
            return 0
        return bisect.bisect_right(self._values, high) - bisect.bisect_left(self._values, low)

    def get_kth_smallest(self, k: int) -> int | None:
        if 1 <= k <= len(self._values):
            return self._values[k - 1]
        return None

    # ---- Level 4 ------------------------------------------------------------
    def undo(self) -> bool:
        if not self._undo:
            return False
        op, value = self._undo.pop()
        if op == "add":
            self._remove(value)
        else:
            self._insert(value)
        self._redo.append((op, value))
        return True

    def redo(self) -> bool:
        if not self._redo:
            return False
        op, value = self._redo.pop()
        if op == "add":
            self._insert(value)
        else:
            self._remove(value)
        self._undo.append((op, value))
        return True

Banking System payments with cashback

Most reported

Reported for Coinbase, Ramp, eBay and Anthropic assessments.

  1. L1create_account, deposit, transfer (returns the source balance or None)
  2. L2top_spenders(n): outgoing desc, then account id asc, as "id(total)"
  3. L3pay() returns "paymentK"; 2% cashback (rounded down) lands 86,400,000 ms later, before other operations at that time; get_payment_status
  4. L4merge_accounts (balance, outgoing, pending cashback, payment ownership) and get_balance(time_at)
Watch for
  • Call the due-cashback processor first in EVERY method, including queries.
  • Log cashback in the balance history at its due time, not when you happened to apply it.
  • A merged-away id returns None from the merge time on, but its earlier history still answers.
Reference solution (banking_system_impl.py, passes every kit test) 
from __future__ import annotations

import bisect
import heapq

from banking_system import BankingSystem

DAY_MS = 24 * 60 * 60 * 1000
CASHBACK_PERCENT = 2


class History:
    """Timeline of (timestamp, value) for one account id. value None = account doesn't exist."""

    def __init__(self):
        self.times: list[int] = []
        self.values: list[int | None] = []

    def record(self, timestamp: int, value: int | None) -> None:
        self.times.append(timestamp)
        self.values.append(value)

    def at(self, timestamp: int) -> int | None:
        i = bisect.bisect_right(self.times, timestamp)   # last entry with time <= timestamp
        return self.values[i - 1] if i else None


class Account:
    def __init__(self, account_id: str):
        self.id = account_id
        self.balance = 0
        self.outgoing = 0
        self.payment_ids: list[str] = []


class Payment:
    def __init__(self, payment_id: str, owner: str, cashback: int, due: int):
        self.id = payment_id
        self.owner = owner
        self.cashback = cashback
        self.due = due
        self.status = "IN_PROGRESS"


class BankingSystemImpl(BankingSystem):

    def __init__(self):
        self.accounts: dict[str, Account] = {}
        self.history: dict[str, History] = {}
        self.payments: dict[str, Payment] = {}
        self.payment_count = 0
        self.pending: list[tuple[int, int, str]] = []   # min-heap of (due, seq, payment_id)

    # ---- shared helpers ----------------------------------------------------
    def _process(self, timestamp: int) -> None:
        """Apply every cashback due at or before `timestamp` (called first by every operation)."""
        while self.pending and self.pending[0][0] <= timestamp:
            due, _, pid = heapq.heappop(self.pending)
            payment = self.payments[pid]
            account = self.accounts[payment.owner]      # owner is updated on merge
            account.balance += payment.cashback
            payment.status = "CASHBACK_RECEIVED"
            self._log(account.id, due, account.balance)  # history uses the due time

    def _log(self, account_id: str, timestamp: int, value: int | None) -> None:
        self.history.setdefault(account_id, History()).record(timestamp, value)

    # ---- Level 1 -------------------------------------------------------------
    def create_account(self, timestamp: int, account_id: str) -> bool:
        self._process(timestamp)
        if account_id in self.accounts:
            return False
        self.accounts[account_id] = Account(account_id)
        self._log(account_id, timestamp, 0)
        return True

    def deposit(self, timestamp: int, account_id: str, amount: int) -> int | None:
        self._process(timestamp)
        account = self.accounts.get(account_id)
        if account is None:
            return None
        account.balance += amount
        self._log(account_id, timestamp, account.balance)
        return account.balance

    def transfer(self, timestamp: int, source_account_id: str, target_account_id: str, amount: int) -> int | None:
        self._process(timestamp)
        source = self.accounts.get(source_account_id)
        target = self.accounts.get(target_account_id)
        if source is None or target is None or source is target or source.balance < amount:
            return None
        source.balance -= amount
        source.outgoing += amount
        target.balance += amount
        self._log(source.id, timestamp, source.balance)
        self._log(target.id, timestamp, target.balance)
        return source.balance

    # ---- Level 2 -------------------------------------------------------------
    def top_spenders(self, timestamp: int, n: int) -> list[str]:
        self._process(timestamp)
        ranked = sorted(self.accounts.values(), key=lambda a: (-a.outgoing, a.id))
        return [f"{a.id}({a.outgoing})" for a in ranked[:n]]

    # ---- Level 3 -------------------------------------------------------------
    def pay(self, timestamp: int, account_id: str, amount: int) -> str | None:
        self._process(timestamp)
        account = self.accounts.get(account_id)
        if account is None or account.balance < amount:
            return None
        account.balance -= amount
        account.outgoing += amount
        self.payment_count += 1
        pid = f"payment{self.payment_count}"
        due = timestamp + DAY_MS
        self.payments[pid] = Payment(pid, account_id, amount * CASHBACK_PERCENT // 100, due)
        account.payment_ids.append(pid)
        heapq.heappush(self.pending, (due, self.payment_count, pid))
        self._log(account_id, timestamp, account.balance)
        return pid

    def get_payment_status(self, timestamp: int, account_id: str, payment: str) -> str | None:
        self._process(timestamp)
        if account_id not in self.accounts:
            return None
        p = self.payments.get(payment)
        if p is None or p.owner != account_id:
            return None
        return p.status

    # ---- Level 4 -------------------------------------------------------------
    def merge_accounts(self, timestamp: int, account_id_1: str, account_id_2: str) -> bool:
        self._process(timestamp)
        if account_id_1 == account_id_2:
            return False
        if account_id_1 not in self.accounts or account_id_2 not in self.accounts:
            return False
        a1 = self.accounts[account_id_1]
        a2 = self.accounts.pop(account_id_2)
        a1.balance += a2.balance
        a1.outgoing += a2.outgoing
        for pid in a2.payment_ids:            # pending cashbacks + status lookups follow the money
            self.payments[pid].owner = account_id_1
            a1.payment_ids.append(pid)
        self._log(account_id_1, timestamp, a1.balance)
        self._log(account_id_2, timestamp, None)   # account_id_2 stops existing now
        return True

    def get_balance(self, timestamp: int, account_id: str, time_at: int) -> int | None:
        self._process(timestamp)
        history = self.history.get(account_id)
        return history.at(time_at) if history else None

Banking System scheduled payments

Reported variant

Level 3 swaps cashback for schedule_payment / cancel_payment (reported for Coinbase).

  1. L1create_account, deposit, transfer
  2. L2top_spenders(n)
  3. L3schedule_payment(ts, id, amount, delay) returns "paymentK"; skipped if funds are short; cancel_payment (owner only, pending only)
  4. L4merge_accounts (pending payments move to account 1) and get_balance(time_at)
Watch for
  • Payments due at the cancel timestamp run before the cancel.
  • Same due time: creation order. A canceled payment can stay in the heap; check its status when popped.

        return self.values[i - 1] if i else None


class Account:
    def __init__(self, account_id: str):
        self.id = account_id
        self.balance = 0
        self.outgoing = 0


class ScheduledPayment:
    def __init__(self, payment_id: str, owner: str, amount: int, due: int):
        self.id = payment_id
        self.owner = owner
        self.amount = amount
        self.due = due
        self.status = "PENDING"   # PENDING -> DONE | SKIPPED | CANCELED


class BankingSystemImpl(BankingSystem):

    def __init__(self):
        self.accounts: dict[str, Account] = {}
        self.history: dict[str, History] = {}
        self.payments: dict[str, ScheduledPayment] = {}
        self.payment_count = 0
        self.queue: list[tuple[int, int, str]] = []   # min-heap of (due, creation_seq, payment_id)

    # ---- shared helpers ----------------------------------------------------
    def _process(self, timestamp: int) -> None:
        """Perform every scheduled payment due at or before `timestamp`, in (due, creation) order."""
        while self.queue and self.queue[0][0] <= timestamp:
            due, _, pid = heapq.heappop(self.queue)
            p = self.payments[pid]
            if p.status != "PENDING":            # canceled while waiting in the heap
                continue
            account = self.accounts[p.owner]
            if account.balance >= p.amount:
                account.balance -= p.amount
                account.outgoing += p.amount
                p.status = "DONE"
                self._log(account.id, due, account.balance)
            else:
                p.status = "SKIPPED"

    def _log(self, account_id: str, timestamp: int, value: int | None) -> None:
        self.history.setdefault(account_id, History()).record(timestamp, value)

    # ---- Level 1 -------------------------------------------------------------
    def create_account(self, timestamp: int, account_id: str) -> bool:
        self._process(timestamp)
        if account_id in self.accounts:
            return False
        self.accounts[account_id] = Account(account_id)
        self._log(account_id, timestamp, 0)
        return True

    def deposit(self, timestamp: int, account_id: str, amount: int) -> int | None:
        self._process(timestamp)
        account = self.accounts.get(account_id)
        if account is None:
            return None
        account.balance += amount
        self._log(account_id, timestamp, account.balance)
        return account.balance

    def transfer(self, timestamp: int, source_account_id: str, target_account_id: str, amount: int) -> int | None:
        self._process(timestamp)
        source = self.accounts.get(source_account_id)
        target = self.accounts.get(target_account_id)
        if source is None or target is None or source is target or source.balance < amount:
            return None
        source.balance -= amount
        source.outgoing += amount
        target.balance += amount
        self._log(source.id, timestamp, source.balance)
        self._log(target.id, timestamp, target.balance)
        return source.balance

    # ---- Level 2 -------------------------------------------------------------
    def top_spenders(self, timestamp: int, n: int) -> list[str]:
        self._process(timestamp)
        ranked = sorted(self.accounts.values(), key=lambda a: (-a.outgoing, a.id))
        return [f"{a.id}({a.outgoing})" for a in ranked[:n]]

    # ---- Level 3 -------------------------------------------------------------
    def schedule_payment(self, timestamp: int, account_id: str, amount: int, delay: int) -> str | None:
        self._process(timestamp)
        if account_id not in self.accounts:
            return None
        self.payment_count += 1
        pid = f"payment{self.payment_count}"
        due = timestamp + delay
        self.payments[pid] = ScheduledPayment(pid, account_id, amount, due)
        heapq.heappush(self.queue, (due, self.payment_count, pid))
        return pid

    def cancel_payment(self, timestamp: int, account_id: str, payment_id: str) -> bool:
        self._process(timestamp)                 # payments due now run before the cancel
        p = self.payments.get(payment_id)
        if p is None or p.owner != account_id or p.status != "PENDING":
            return False
        p.status = "CANCELED"                    # lazily dropped when popped from the heap
        return True

    # ---- Level 4 -------------------------------------------------------------
    def merge_accounts(self, timestamp: int, account_id_1: str, account_id_2: str) -> bool:
        self._process(timestamp)
        if account_id_1 == account_id_2:
            return False
        if account_id_1 not in self.accounts or account_id_2 not in self.accounts:
            return False
        a1 = self.accounts[account_id_1]
        a2 = self.accounts.pop(account_id_2)
        a1.balance += a2.balance
        a1.outgoing += a2.outgoing
        for p in self.payments.values():         # pending payments now charge account 1
            if p.owner == account_id_2:
                p.owner = account_id_1
        self._log(account_id_1, timestamp, a1.balance)
        self._log(account_id_2, timestamp, None)
        return True

    def get_balance(self, timestamp: int, account_id: str, time_at: int) -> int | None:
        self._process(timestamp)
        history = self.history.get(account_id)
        return history.at(time_at) if history else None

Cloud Storage users, merge, backup

Very common

Reported for Ramp, Anthropic and Dropbox assessments.

  1. L1add_file, get_file_size, delete_file
  2. L2get_n_largest(prefix, n) as ["name(size)"]: size desc, name asc
  3. L3add_user(capacity), add_file_by returns remaining capacity, merge_user (capacities add, files move)
  4. L4backup_user / restore_user (skip names now owned by someone else)
Watch for
  • Treat admin as a user with capacity None so every add goes through one helper.
  • Deleting a file frees its owner's capacity. Backups are copies, not references.
Reference solution (cloud_storage_impl.py, passes every kit test) 
from __future__ import annotations

from cloud_storage import CloudStorage

ADMIN = "admin"


class File:
    def __init__(self, name: str, size: int, owner: str):
        self.name = name
        self.size = size
        self.owner = owner


class User:
    def __init__(self, user_id: str, capacity: int | None):
        self.id = user_id
        self.capacity = capacity            # None = unlimited (admin)
        self.used = 0
        self.files: set[str] = set()
        self.backup: dict[str, int] | None = None

    def remaining(self) -> int | None:
        return None if self.capacity is None else self.capacity - self.used


class CloudStorageImpl(CloudStorage):

    def __init__(self):
        self.files: dict[str, File] = {}
        self.users: dict[str, User] = {ADMIN: User(ADMIN, None)}

    # ---- primitives shared by every level -----------------------------------
    def _add(self, user_id: str, name: str, size: int) -> bool:
        user = self.users.get(user_id)
        if user is None or name in self.files:
            return False
        if user.capacity is not None and user.used + size > user.capacity:
            return False
        self.files[name] = File(name, size, user_id)
        user.used += size
        user.files.add(name)
        return True

    def _delete(self, name: str) -> int | None:
        f = self.files.pop(name, None)
        if f is None:
            return None
        owner = self.users[f.owner]
        owner.used -= f.size
        owner.files.discard(name)
        return f.size

    # ---- Level 1 -------------------------------------------------------------
    def add_file(self, name: str, size: int) -> bool:
        return self._add(ADMIN, name, size)

    def get_file_size(self, name: str) -> int | None:
        f = self.files.get(name)
        return f.size if f else None

    def delete_file(self, name: str) -> int | None:
        return self._delete(name)

    # ---- Level 2 -------------------------------------------------------------
    def get_n_largest(self, prefix: str, n: int) -> list[str]:
        matches = [f for f in self.files.values() if f.name.startswith(prefix)]
        matches.sort(key=lambda f: (-f.size, f.name))
        return [f"{f.name}({f.size})" for f in matches[:n]]

    # ---- Level 3 -------------------------------------------------------------
    def add_user(self, user_id: str, capacity: int) -> bool:
        if user_id in self.users:
            return False
        self.users[user_id] = User(user_id, capacity)
        return True

    def add_file_by(self, user_id: str, name: str, size: int) -> int | None:
        if not self._add(user_id, name, size):
            return None
        return self.users[user_id].remaining()

    def merge_user(self, user_id_1: str, user_id_2: str) -> int | None:
        if user_id_1 == user_id_2 or user_id_1 not in self.users or user_id_2 not in self.users:
            return None
        u1 = self.users[user_id_1]
        u2 = self.users.pop(user_id_2)          # its backup disappears with it
        for name in u2.files:
            self.files[name].owner = user_id_1
        u1.files |= u2.files
        u1.used += u2.used
        u1.capacity += u2.capacity
        return u1.remaining()

    # ---- Level 4 -------------------------------------------------------------
    def backup_user(self, user_id: str) -> int | None:
        user = self.users.get(user_id)
        if user is None:
            return None
        user.backup = {name: self.files[name].size for name in user.files}   # copy, not a reference
        return len(user.backup)

    def restore_user(self, user_id: str) -> int | None:
        user = self.users.get(user_id)
        if user is None:
            return None
        for name in list(user.files):            # copy: _delete mutates user.files
            self._delete(name)
        restored = 0
        for name, size in sorted((user.backup or {}).items()):
            if name in self.files:               # taken by someone else meanwhile
                continue
            self.files[name] = File(name, size, user_id)
            user.used += size
            user.files.add(name)
            restored += 1
        return restored

Reported variant

Variant with copy, prefix+suffix search, capacity updates and compression.

  2. L2find_file(prefix, suffix)
  3. L3add_user, add_file_by, update_capacity (evict largest, ties by name) returns the count removed
  4. L4compress_file (".COMPRESSED", half size) and decompress_file

  • Decompression capacity check uses the size difference.
  • update_capacity returns how many files were deleted, not the remaining capacity.

from __future__ import annotations

from cloud_storage import CloudStorage

ADMIN = "admin"
SUFFIX = ".COMPRESSED"


class File:
    def __init__(self, name: str, size: int, owner: str, original_size: int | None = None):
        self.name = name
        self.size = size
        self.owner = owner
        self.original_size = original_size    # set only for compressed files


class User:
    def __init__(self, user_id: str, capacity: int | None):
        self.id = user_id
        self.capacity = capacity              # None = unlimited (admin)
        self.used = 0

    def fits(self, extra: int) -> bool:
        return self.capacity is None or self.used + extra <= self.capacity

    def remaining(self) -> int | None:
        return None if self.capacity is None else self.capacity - self.used


class CloudStorageImpl(CloudStorage):

    def __init__(self):
        self.files: dict[str, File] = {}
        self.users: dict[str, User] = {ADMIN: User(ADMIN, None)}

    # ---- primitives ----------------------------------------------------------
    def _put(self, f: File) -> None:
        self.files[f.name] = f
        self.users[f.owner].used += f.size

    def _remove(self, name: str) -> File:
        f = self.files.pop(name)
        self.users[f.owner].used -= f.size
        return f

    def _owned(self, user_id: str, name: str) -> File | None:
        f = self.files.get(name)
        if user_id not in self.users or f is None or f.owner != user_id:
            return None
        return f

    # ---- Level 1 -------------------------------------------------------------
    def add_file(self, name: str, size: int) -> bool:
        if name in self.files:
            return False
        self._put(File(name, size, ADMIN))
        return True

    def copy_file(self, name_from: str, name_to: str) -> bool:
        src = self.files.get(name_from)
        if src is None or name_to in self.files:
            return False
        if not self.users[src.owner].fits(src.size):
            return False
        self._put(File(name_to, src.size, src.owner, src.original_size))
        return True

    def get_file_size(self, name: str) -> int | None:
        f = self.files.get(name)
        return f.size if f else None

    # ---- Level 2 -------------------------------------------------------------
    def find_file(self, prefix: str, suffix: str) -> list[str]:
        matches = [f for f in self.files.values() if f.name.startswith(prefix) and f.name.endswith(suffix)]
        matches.sort(key=lambda f: (-f.size, f.name))
        return [f"{f.name}({f.size})" for f in matches]

    # ---- Level 3 -------------------------------------------------------------
    def add_user(self, user_id: str, capacity: int) -> bool:
        if user_id in self.users:
            return False
        self.users[user_id] = User(user_id, capacity)
        return True

    def add_file_by(self, user_id: str, name: str, size: int) -> int | None:
        user = self.users.get(user_id)
        if user is None or name in self.files or not user.fits(size):
            return None
        self._put(File(name, size, user_id))
        return user.remaining()

    def update_capacity(self, user_id: str, capacity: int) -> int | None:
        user = self.users.get(user_id)
        if user is None:
            return None
        user.capacity = capacity
        mine = sorted((f for f in self.files.values() if f.owner == user_id), key=lambda f: (-f.size, f.name))
        removed = 0
        for f in mine:
            if user.used <= capacity:
                break
            self._remove(f.name)
            removed += 1
        return removed

    # ---- Level 4 -------------------------------------------------------------
    def compress_file(self, user_id: str, name: str) -> int | None:
        f = self._owned(user_id, name)
        if f is None or name.endswith(SUFFIX) or name + SUFFIX in self.files:
            return None
        self._remove(name)
        self._put(File(name + SUFFIX, f.size // 2, user_id, original_size=f.size))
        return self.users[user_id].remaining()

    def decompress_file(self, user_id: str, name: str) -> int | None:
        f = self._owned(user_id, name)
        if f is None or not name.endswith(SUFFIX) or f.original_size is None:
            return None
        original = name[: -len(SUFFIX)]
        user = self.users[user_id]
        if original in self.files or not user.fits(f.original_size - f.size):
            return None
        self._remove(name)
        self._put(File(original, f.original_size, user_id))
        return user.remaining()

File Hosting TTL + rollback

Seen in mocks

Shape of the public CodeSignal-style mock: exceptions, top-10 search, TTL, rollback.

  1. L1file_upload (raise if exists), file_get, file_copy (raise if missing; overwrite)
  2. L2file_search(prefix): top 10 names by size desc, then name
  3. L3*_at versions; files with ttl live during [t, t + ttl)
  4. L4rollback(timestamp, time_to): restore the state at time_to, keeping remaining TTLs
Watch for
  • Some operations must RAISE instead of returning a value.
  • A copy keeps the source's absolute expiry. Record a snapshot after every change, including the rollback.
Reference solution (file_hosting_impl.py, passes every kit test) 
from __future__ import annotations

import bisect

from file_hosting import FileHosting

SEARCH_LIMIT = 10


class FileHostingImpl(FileHosting):
    """
    State: name -> (size, expires_at or None).
    Every timestamped change also appends a snapshot (time, copy of state) so
    rollback can find "the state at time T" with a binary search.
    """

    def __init__(self):
        self.files: dict[str, tuple[int, int | None]] = {}
        self.snap_times: list[int] = []
        self.snaps: list[dict[str, tuple[int, int | None]]] = []

    # ---- helpers ---------------------------------------------------------------
    def _alive(self, name: str, timestamp: int | None) -> tuple[int, int | None] | None:
        rec = self.files.get(name)
        if rec is None:
            return None
        expires = rec[1]
        if timestamp is not None and expires is not None and timestamp >= expires:
            return None
        return rec

    def _save(self, timestamp: int) -> None:
        self.snap_times.append(timestamp)
        self.snaps.append(dict(self.files))       # values are immutable tuples -> shallow copy is enough

    def _search(self, prefix: str, timestamp: int | None) -> list[str]:
        hits = []
        for name in self.files:
            rec = self._alive(name, timestamp)
            if rec is not None and name.startswith(prefix):
                hits.append((rec[0], name))
        hits.sort(key=lambda sn: (-sn[0], sn[1]))
        return [name for _, name in hits[:SEARCH_LIMIT]]

    # ---- Level 1 ---------------------------------------------------------------
    def file_upload(self, file_name: str, size: int) -> None:
        if file_name in self.files:
            raise RuntimeError(f"file {file_name} already exists")
        self.files[file_name] = (size, None)

    def file_get(self, file_name: str) -> int | None:
        rec = self.files.get(file_name)
        return rec[0] if rec else None

    def file_copy(self, source: str, dest: str) -> None:
        if source not in self.files:
            raise RuntimeError(f"file {source} not found")
        self.files[dest] = self.files[source]

    # ---- Level 2 ---------------------------------------------------------------
    def file_search(self, prefix: str) -> list[str]:
        return self._search(prefix, None)

    # ---- Level 3 ---------------------------------------------------------------
    def file_upload_at(self, timestamp: int, file_name: str, file_size: int, ttl: int | None = None) -> None:
        if self._alive(file_name, timestamp) is not None:
            raise RuntimeError(f"file {file_name} already exists")
        self.files[file_name] = (file_size, None if ttl is None else timestamp + ttl)
        self._save(timestamp)

    def file_get_at(self, timestamp: int, file_name: str) -> int | None:
        rec = self._alive(file_name, timestamp)
        return rec[0] if rec else None

    def file_copy_at(self, timestamp: int, source: str, dest: str) -> None:
        rec = self._alive(source, timestamp)
        if rec is None:
            raise RuntimeError(f"file {source} not found")
        self.files[dest] = rec                     # same size, same expiry moment
        self._save(timestamp)

    def file_search_at(self, timestamp: int, prefix: str) -> list[str]:
        return self._search(prefix, timestamp)

    # ---- Level 4 ---------------------------------------------------------------
    def rollback(self, timestamp: int, time_to: int) -> None:
        i = bisect.bisect_right(self.snap_times, time_to)   # last snapshot taken at or before time_to
        base = self.snaps[i - 1] if i else {}
        restored: dict[str, tuple[int, int | None]] = {}
        for name, (size, expires) in base.items():
            if expires is None:
                restored[name] = (size, None)
            elif expires > time_to:                           # alive at time_to
                restored[name] = (size, timestamp + (expires - time_to))
        self.files = restored
        self._save(timestamp)

Very common

from __future__ import annotations

import bisect

from in_memory_db import InMemoryDB

# A field is stored as (value, expires_at) where expires_at is None for "never".
Entry = tuple


class InMemoryDBImpl(InMemoryDB):

    def __init__(self):
        self.data: dict[str, dict[str, Entry]] = {}
        self.backup_times: list[int] = []
        self.backups: list[dict[str, dict[str, tuple[str, int | None]]]] = []   # remaining TTLs

    # ---- core helpers (timestamp None = "ignore expiry", used by Level 1-2) --
    @staticmethod
    def _alive(entry: Entry, timestamp: int | None) -> bool:
        expires = entry[1]
        return timestamp is None or expires is None or timestamp < expires

    def _set(self, key: str, field: str, value: str, expires: int | None) -> None:
        self.data.setdefault(key, {})[field] = (value, expires)

    def _get(self, key: str, field: str, timestamp: int | None) -> str | None:
        entry = self.data.get(key, {}).get(field)
        if entry is None or not self._alive(entry, timestamp):
            return None
        return entry[0]

    def _delete(self, key: str, field: str, timestamp: int | None) -> bool:
        if self._get(key, field, timestamp) is None:
            return False
        record = self.data[key]
        del record[field]
        if not record:
            del self.data[key]
        return True

    def _scan(self, key: str, prefix: str, timestamp: int | None) -> list[str]:
        record = self.data.get(key, {})
        fields = sorted(f for f, e in record.items() if f.startswith(prefix) and self._alive(e, timestamp))
        return [f"{f}({record[f][0]})" for f in fields]

    # ---- Level 1 ---------------------------------------------------------------
    def set(self, key: str, field: str, value: str) -> None:
        self._set(key, field, value, None)

    def get(self, key: str, field: str) -> str | None:
        return self._get(key, field, None)

    def delete(self, key: str, field: str) -> bool:
        return self._delete(key, field, None)

    # ---- Level 2 ---------------------------------------------------------------
    def scan(self, key: str) -> list[str]:
        return self._scan(key, "", None)

    def scan_by_prefix(self, key: str, prefix: str) -> list[str]:
        return self._scan(key, prefix, None)

    # ---- Level 3 ---------------------------------------------------------------
    def set_at(self, key: str, field: str, value: str, timestamp: int) -> None:
        self._set(key, field, value, None)

    def set_at_with_ttl(self, key: str, field: str, value: str, timestamp: int, ttl: int) -> None:
        self._set(key, field, value, timestamp + ttl)

    def delete_at(self, key: str, field: str, timestamp: int) -> bool:
        return self._delete(key, field, timestamp)

    def get_at(self, key: str, field: str, timestamp: int) -> str | None:
        return self._get(key, field, timestamp)

    def scan_at(self, key: str, timestamp: int) -> list[str]:
        return self._scan(key, "", timestamp)

    def scan_by_prefix_at(self, key: str, prefix: str, timestamp: int) -> list[str]:
        return self._scan(key, prefix, timestamp)

    # ---- Level 4 ---------------------------------------------------------------
    def backup(self, timestamp: int) -> int:
        snapshot: dict[str, dict[str, tuple[str, int | None]]] = {}
        for key, record in self.data.items():
            saved = {}
            for field, (value, expires) in record.items():
                if self._alive((value, expires), timestamp):
                    saved[field] = (value, None if expires is None else expires - timestamp)
            if saved:
                snapshot[key] = saved
        self.backup_times.append(timestamp)
        self.backups.append(snapshot)
        return len(snapshot)

    def restore(self, timestamp: int, timestamp_to_restore: int) -> None:
        i = bisect.bisect_right(self.backup_times, timestamp_to_restore) - 1   # latest backup <= target
        snapshot = self.backups[i]
        self.data = {
            key: {field: (value, None if remaining is None else timestamp + remaining)
                  for field, (value, remaining) in record.items()}
            for key, record in snapshot.items()
        }

        self.compensation = compensation
        self.position_since = 0                       # when the current position became active
        self.sessions: list[Session] = []             # finished sessions only
        self.entered_at: int | None = None            # set while the worker is in the office
        self.pending: tuple[str, int, int] | None = None   # (position, compensation, start_timestamp)

    def total_time(self) -> int:
        return sum(s.end - s.start for s in self.sessions)

    def time_in_current_position(self) -> int:
        return sum(s.end - s.start for s in self.sessions if s.start >= self.position_since)


def _overlap(a1: int, a2: int, b1: int, b2: int) -> int:
    return max(0, min(a2, b2) - max(a1, b1))


class WorkerRegistryImpl(WorkerRegistry):

    def __init__(self):
        self.workers: dict[str, Worker] = {}
        self.double_periods: list[tuple[int, int]] = []

    # ---- Level 1 ---------------------------------------------------------------
    def add_worker(self, worker_id: str, position: str, compensation: int) -> bool:
        if worker_id in self.workers:
            return False
        self.workers[worker_id] = Worker(worker_id, position, compensation)
        return True

    def register(self, worker_id: str, timestamp: int) -> str:
        w = self.workers.get(worker_id)
        if w is None:
            return "invalid_request"
        if w.entered_at is None:                                  # entering
            if w.pending is not None and timestamp >= w.pending[2]:
                w.position, w.compensation, _ = w.pending         # promotion becomes active now
                w.position_since = timestamp
                w.pending = None
            w.entered_at = timestamp
        else:                                                     # leaving
            w.sessions.append(Session(w.entered_at, timestamp, w.position, w.compensation))
            w.entered_at = None
        return "registered"

    def get(self, worker_id: str) -> int | None:
        w = self.workers.get(worker_id)
        return w.total_time() if w else None

    # ---- Level 2 ---------------------------------------------------------------
    def top_n_workers(self, n: int, position: str) -> list[str]:
        ranked = sorted(
            ((w.time_in_current_position(), w.id) for w in self.workers.values() if w.position == position),
            key=lambda tw: (-tw[0], tw[1]),
        )
        return [f"{wid}({t})" for t, wid in ranked[:n]]

    # ---- Level 3 ---------------------------------------------------------------
    def promote(self, worker_id: str, new_position: str, new_compensation: int, start_timestamp: int) -> str:
        w = self.workers.get(worker_id)
        if w is None or w.pending is not None:
            return "invalid_request"
        w.pending = (new_position, new_compensation, start_timestamp)
        return "success"

    def calc_salary(self, worker_id: str, start_timestamp: int, end_timestamp: int) -> int | None:
        w = self.workers.get(worker_id)
        if w is None:
            return None
        doubles = self._merged_double_periods()
        total = 0
        for s in w.sessions:
            a, b = max(s.start, start_timestamp), min(s.end, end_timestamp)
            if a >= b:
                continue
            extra = sum(_overlap(a, b, x, y) for x, y in doubles)   # double time is paid once more
            total += s.compensation * ((b - a) + extra)
        return total

    # ---- Level 4 ---------------------------------------------------------------
    def set_double_paid(self, start_timestamp: int, end_timestamp: int) -> None:
        self.double_periods.append((start_timestamp, end_timestamp))

    def _merged_double_periods(self) -> list[tuple[int, int]]:
        merged: list[list[int]] = []
        for x, y in sorted(self.double_periods):
            if merged and x <= merged[-1][1]:
                merged[-1][1] = max(merged[-1][1], y)
            else:
                merged.append([x, y])
        return [(x, y) for x, y in merged]

Task Manager assignments + quotas

Reported

Task management with quotas (reported for Ramp in 2026 and Airbnb).

  1. L1add_task returns "task_id_K"; update_task; get_task returns a JSON string
  2. L2search_tasks(filter, max), list_tasks_sorted(limit): priority desc, creation asc
  3. L3add_user(quota), assign_task (active during [ts, finish)), get_user_tasks
  4. L4complete_task, get_overdue_assignments
Watch for
  • Never sort by id strings: "task_id_10" < "task_id_2".
  • Build JSON with json.dumps. Count the quota at the assignment timestamp.
Reference solution (task_manager_impl.py, passes every kit test) 
from __future__ import annotations

import json

from task_manager import TaskManager


class Task:
    def __init__(self, task_id: str, seq: int, name: str, priority: int):
        self.id = task_id
        self.seq = seq                  # creation order; never sort by the id string ("task_id_10" < "task_id_2")
        self.name = name
        self.priority = priority


class Assignment:
    def __init__(self, task_id: str, start: int, finish: int, seq: int):
        self.task_id = task_id
        self.start = start
        self.finish = finish
        self.seq = seq                  # assignment order
        self.completed_at: int | None = None

    def active(self, t: int) -> bool:
        return self.completed_at is None and self.start <= t < self.finish

    def overdue(self, t: int) -> bool:
        return self.completed_at is None and self.finish <= t


class User:
    def __init__(self, user_id: str, quota: int):
        self.id = user_id
        self.quota = quota
        self.assignments: list[Assignment] = []


class TaskManagerImpl(TaskManager):

    def __init__(self):
        self.tasks: dict[str, Task] = {}
        self.users: dict[str, User] = {}
        self.task_count = 0
        self.assign_count = 0

    def _ordered(self, tasks) -> list[str]:
        return [t.id for t in sorted(tasks, key=lambda t: (-t.priority, t.seq))]

    # ---- Level 1 ---------------------------------------------------------------
    def add_task(self, timestamp: int, name: str, priority: int) -> str:
        self.task_count += 1
        task_id = f"task_id_{self.task_count}"
        self.tasks[task_id] = Task(task_id, self.task_count, name, priority)
        return task_id

    def update_task(self, timestamp: int, task_id: str, name: str, priority: int) -> bool:
        task = self.tasks.get(task_id)
        if task is None:
            return False
        task.name, task.priority = name, priority
        return True

    def get_task(self, timestamp: int, task_id: str) -> str | None:
        task = self.tasks.get(task_id)
        if task is None:
            return None
        return json.dumps({"name": task.name, "priority": task.priority})

    # ---- Level 2 ---------------------------------------------------------------
    def search_tasks(self, timestamp: int, name_filter: str, max_results: int) -> list[str]:
        if max_results <= 0:
            return []
        return self._ordered(t for t in self.tasks.values() if name_filter in t.name)[:max_results]

    def list_tasks_sorted(self, timestamp: int, limit: int) -> list[str]:
        return self._ordered(self.tasks.values())[:max(limit, 0)]

    # ---- Level 3 ---------------------------------------------------------------
    def add_user(self, timestamp: int, user_id: str, quota: int) -> bool:
        if user_id in self.users:
            return False
        self.users[user_id] = User(user_id, quota)
        return True

    def assign_task(self, timestamp: int, task_id: str, user_id: str, finish_time: int) -> bool:
        user = self.users.get(user_id)
        if user is None or task_id not in self.tasks:
            return False
        if sum(a.active(timestamp) for a in user.assignments) >= user.quota:
            return False
        self.assign_count += 1
        user.assignments.append(Assignment(task_id, timestamp, finish_time, self.assign_count))
        return True

    def get_user_tasks(self, timestamp: int, user_id: str) -> list[str]:
        user = self.users.get(user_id)
        if user is None:
            return []
        active = sorted((a for a in user.assignments if a.active(timestamp)), key=lambda a: (a.finish, a.seq))
        return [a.task_id for a in active]

    # ---- Level 4 ---------------------------------------------------------------
    def complete_task(self, timestamp: int, task_id: str, user_id: str) -> bool:
        user = self.users.get(user_id)
        if user is None:
            return False
        candidates = [a for a in user.assignments if a.task_id == task_id and a.active(timestamp)]
        if not candidates:
            return False
        min(candidates, key=lambda a: (a.finish, a.seq)).completed_at = timestamp
        return True

    def get_overdue_assignments(self, timestamp: int, user_id: str) -> list[str]:
        user = self.users.get(user_id)
        if user is None:
            return []
        overdue = sorted((a for a in user.assignments if a.overdue(timestamp)), key=lambda a: (a.finish, a.seq))
        return [a.task_id for a in overdue]

Text Editor cursor, clipboard, undo, documents

Extra practice

Different shape: cursor and string state, plus a Level 4 encapsulation refactor.

  1. L1insert, move_cursor, delete_forward, backspace, get_cursor
  2. L2select, copy, paste (a selection gets replaced)
  3. L3undo / redo restore both text and cursor
  4. L4create_document / switch_document: per-document state, shared clipboard
Watch for
  • One replace helper for every edit. Only record real changes.
Reference solution (text_editor_impl.py, passes every kit test) 
from __future__ import annotations

from text_editor import TextEditor


class Document:
    def __init__(self):
        self.text = ""
        self.cursor = 0
        self.selection: tuple[int, int] | None = None
        self.undo_stack: list[tuple[str, int]] = []   # (text, cursor) before each change
        self.redo_stack: list[tuple[str, int]] = []   # (text, cursor) after each undone change


class TextEditorImpl(TextEditor):

    def __init__(self):
        self.docs: dict[str, Document] = {"untitled": Document()}
        self.current = "untitled"
        self.clipboard = ""

    @property
    def doc(self) -> Document:
        return self.docs[self.current]

    # ---- the one place where text changes -------------------------------------
    def _replace(self, start: int, end: int, new: str, cursor_after: int) -> str:
        d = self.doc
        text = d.text[:start] + new + d.text[end:]
        if text != d.text:                           # only real changes are undoable
            d.undo_stack.append((d.text, d.cursor))
            d.redo_stack.clear()
            d.text = text
            d.cursor = cursor_after
        d.selection = None
        return d.text

    def _clamp(self, p: int) -> int:
        return max(0, min(p, len(self.doc.text)))

    # ---- Level 1 ---------------------------------------------------------------
    def insert(self, text: str) -> str:
        d = self.doc
        start, end = d.selection or (d.cursor, d.cursor)
        return self._replace(start, end, text, start + len(text))

    def move_cursor(self, position: int) -> str:
        self.doc.cursor = self._clamp(position)
        self.doc.selection = None
        return self.doc.text

    def delete_forward(self) -> str:
        d = self.doc
        if d.selection:
            start, end = d.selection
            return self._replace(start, end, "", start)
        return self._replace(d.cursor, min(d.cursor + 1, len(d.text)), "", d.cursor)

    def backspace(self) -> str:
        d = self.doc
        if d.selection:
            start, end = d.selection
            return self._replace(start, end, "", start)
        start = max(d.cursor - 1, 0)
        return self._replace(start, d.cursor, "", start)

    def get_cursor(self) -> int:
        return self.doc.cursor

    # ---- Level 2 ---------------------------------------------------------------
    def select(self, left: int, right: int) -> str:
        d = self.doc
        left, right = sorted((self._clamp(left), self._clamp(right)))
        d.cursor = right
        d.selection = (left, right) if left < right else None
        return d.text[left:right]

    def copy(self) -> str:
        d = self.doc
        if d.selection:
            start, end = d.selection
            self.clipboard = d.text[start:end]
        return self.clipboard

    def paste(self) -> str:
        return self.insert(self.clipboard)

    # ---- Level 3 ---------------------------------------------------------------
    def undo(self) -> str:
        d = self.doc
        if d.undo_stack:
            d.redo_stack.append((d.text, d.cursor))
            d.text, d.cursor = d.undo_stack.pop()
        d.selection = None
        return d.text

    def redo(self) -> str:
        d = self.doc
        if d.redo_stack:
            d.undo_stack.append((d.text, d.cursor))
            d.text, d.cursor = d.redo_stack.pop()
        d.selection = None
        return d.text

    # ---- Level 4 ---------------------------------------------------------------
    def create_document(self, name: str) -> bool:
        if name in self.docs:
            return False
        self.docs[name] = Document()
        return True

    def switch_document(self, name: str) -> str | None:
        if name not in self.docs:
            return None
        self.current = name
        return self.doc.text

Job Scheduler priorities + dependencies

Extra practice

Different shape: priority queue plus a dependency graph.

  1. L1add_job, next_job (priority desc, FIFO), complete_job, get_status
  2. L2peek_jobs, jobs_with_status
  3. L3add_dependency with cycle detection; blocked vs queued
  4. L4cancel_job cascades to every dependent
Watch for
  • Derive queued/blocked on demand. DFS for cycles, BFS for the cascade.
Reference solution (job_scheduler_impl.py, passes every kit test) 
from __future__ import annotations

from collections import deque

from job_scheduler import JobScheduler

PENDING, RUNNING, DONE, CANCELED = "pending", "running", "done", "canceled"


class Job:
    def __init__(self, job_id: str, priority: int, seq: int):
        self.id = job_id
        self.priority = priority
        self.seq = seq                         # insertion order for tie-breaks
        self.state = PENDING                   # pending = not started, not canceled
        self.prereqs: set[str] = set()         # jobs this one waits for
        self.dependents: set[str] = set()      # jobs waiting for this one


class JobSchedulerImpl(JobScheduler):

    def __init__(self):
        self.jobs: dict[str, Job] = {}
        self.count = 0

    # ---- helpers ---------------------------------------------------------------
    def _ready(self, job: Job) -> bool:
        return job.state == PENDING and all(self.jobs[p].state == DONE for p in job.prereqs)

    def _status(self, job: Job) -> str:
        if job.state == PENDING:
            return "queued" if self._ready(job) else "blocked"
        return job.state

    def _ready_in_order(self) -> list[Job]:
        return sorted((j for j in self.jobs.values() if self._ready(j)), key=lambda j: (-j.priority, j.seq))

    def _depends_on(self, start: str, target: str) -> bool:
        """True if `start` (transitively) waits for `target`."""
        stack, seen = [start], set()
        while stack:
            cur = stack.pop()
            if cur == target:
                return True
            if cur in seen:
                continue
            seen.add(cur)
            stack.extend(self.jobs[cur].prereqs)
        return False

    # ---- Level 1 ---------------------------------------------------------------
    def add_job(self, job_id: str, priority: int) -> bool:
        if job_id in self.jobs:
            return False
        self.count += 1
        self.jobs[job_id] = Job(job_id, priority, self.count)
        return True

    def next_job(self) -> str | None:
        ready = self._ready_in_order()
        if not ready:
            return None
        ready[0].state = RUNNING
        return ready[0].id

    def complete_job(self, job_id: str) -> bool:
        job = self.jobs.get(job_id)
        if job is None or job.state != RUNNING:
            return False
        job.state = DONE
        return True

    def get_status(self, job_id: str) -> str | None:
        job = self.jobs.get(job_id)
        return self._status(job) if job else None

    # ---- Level 2 ---------------------------------------------------------------
    def peek_jobs(self, n: int) -> list[str]:
        return [j.id for j in self._ready_in_order()[:max(n, 0)]]

    def jobs_with_status(self, status: str) -> list[str]:
        return sorted(j.id for j in self.jobs.values() if self._status(j) == status)

    # ---- Level 3 ---------------------------------------------------------------
    def add_dependency(self, job_id: str, prerequisite_id: str) -> bool:
        job, pre = self.jobs.get(job_id), self.jobs.get(prerequisite_id)
        if job is None or pre is None or job is pre:
            return False
        if job.state != PENDING or pre.state == CANCELED or prerequisite_id in job.prereqs:
            return False
        if self._depends_on(prerequisite_id, job_id):   # edge would close a cycle
            return False
        job.prereqs.add(prerequisite_id)
        pre.dependents.add(job_id)
        return True

    # ---- Level 4 ---------------------------------------------------------------
    def cancel_job(self, job_id: str) -> list[str]:
        job = self.jobs.get(job_id)
        if job is None or job.state != PENDING:
            return []
        canceled, queue = [], deque([job_id])
        while queue:                                    # BFS over dependents
            cur = self.jobs[queue.popleft()]
            if cur.state != PENDING:
                continue
            cur.state = CANCELED
            canceled.append(cur.id)
            queue.extend(cur.dependents)
        return sorted(canceled)
